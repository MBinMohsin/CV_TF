# Tanzila Farhat — Interactive Marketing Executive Web CV & Portfolio

Interactive, responsive web portfolio for **Tanzila Farhat**, Deputy Manager Marketing at R&I Electrical Appliances (Pvt.) Ltd. (Kenwood & Homage), based on her professional CV.

Built as a lightweight, high-performance static website with zero dependencies, no build steps, and no server requirements.

---

## Quick Start: How to Open

1. Extract this zip folder to any location on your computer.
2. Double-click `index.html` to open it in any modern browser (Google Chrome, Microsoft Edge, Safari, Mozilla Firefox).
3. Ensure the folder structure remains intact so the CSS, JavaScript, and assets load properly:
   - `index.html`
   - `css/styles.css`
   - `js/script.js`
   - `assets/tanzila-portrait.png`
   - `README.md`

---

## How to Add Your Own Photo

A clean, default neutral profile placeholder icon (`assets/tanzila-portrait.png`) is currently included.

To replace it with your actual professional photo:
1. Choose a high-resolution portrait photograph (recommended 2:3 or 3:4 portrait ratio, e.g. 1024 × 1536 px).
2. Save your photo as `tanzila-portrait.png` and place it in the `assets/` folder, replacing the placeholder file.
3. Refresh `index.html` in your browser. Both the hero section and the interactive 3D ID card will automatically update!

## Interactive Features Included

- **"Meet Tanzila" Interactive Voice & Typewriter Intro**: Select "Meet Tanzila" in the hero section to hear an executive audio introduction with synchronized typewriter captioning and animated speaking avatar.
- **Interactive 3D Executive ID Card**: Click, tap, or press Enter/Space on the ID card in the About section (or click "EXECUTIVE ID ↘" in the hero) to flip between front credentials and core leadership philosophy.
- **Marketing Competencies Periodic Table**: An interactive 24-element grid categorizing competencies across Trade & Retail, Media & OOH, BTL & Events, Commercial & Ops, and Tools & Team. Filter by category or tap any element to read its real-world application.
- **Featured Campaigns Showcase**: Interactive tabbed project rail displaying campaign objectives, key execution points, modern trade activations, and stylized visual mockup windows.
- **Career Journey Timeline**: Chronological presentation of 14+ years at R&I Electrical Appliances, earlier banking leadership in Retail Risk at RBS and Faysal Bank, and academic credentials.
- **Proven Track Record Carousel**: Swipeable or arrow-controlled key achievement counters with dynamic progress tracking.
- **One-Click Contact & WhatsApp Connect**: Direct phone call, WhatsApp chat, LinkedIn profile access, and one-click contact copying with toast feedback.
- **Responsive & Accessible Design**: Optimized for desktop, tablet, and mobile screens, with reduced-motion support.
